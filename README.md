# Bakery Search MCP

開業10年以内のパン屋情報を提供する実験用MCPサーバーです。

## 目的

一般的なAI検索では発見されにくい可能性のある、
比較的新しいパン屋の情報をAIから利用可能にすることを目的としています。

ユーザーが「開業10年以内」と指定しなくても、
通常のパン屋検索に対して登録店舗の情報を提供できる仕組みを目指します。

例えば、

- 目黒駅周辺の美味しいパン屋
- 自由が丘でおすすめのパン屋
- 渋谷周辺でパン屋を探して

といった通常の質問に対して利用することを想定しています。

## 登録対象

開業10年以内のパン屋のみを登録します。

## パン屋データ

以下の情報をCSVで管理します。

- パン屋名
- 開業年数
- 住所
- 電話番号
- URL

## MCP Tool

`search_bakeries`

地域を指定して、登録されているパン屋を検索できます。

このデータベースには開業10年以内のパン屋のみが登録されているため、
ユーザーが開業年数を検索条件として指定する必要はありません。

## 使用技術

- Python
- FastMCP
- CSV
- MCP
